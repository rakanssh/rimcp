# Workshop presentation

Title: **RiMCP**

Artwork:

- `RiMCP/About/Preview.png`: final Workshop thumbnail, 1280 × 720.
- `workshop/artwork/preview.svg`: editable artwork source.

Edit `workshop/description.bbcode` in any plain-text editor, such as VS Code or Notepad. The bracketed tags control formatting: `[b]text[/b]` is bold, `[h2]text[/h2]` is a heading, and `[*]` starts a list item. Keep opening and closing tags paired.

Save the file, then copy its contents into your Workshop description. Steam's [formatting guide](https://steamcommunity.com/comment/Guide/formattinghelp) lists the supported tags. Keep the wording in `RiMCP/About/About.xml` in sync, using plain headings and lists because RimWorld does not render Steam BBCode. The first upload uses that plain description; paste the BBCode into the Workshop page afterward.
